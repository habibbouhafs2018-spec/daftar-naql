# دفتر النقل — نسخة PWA قابلة للنشر

## محتويات الحزمة
- `index.html`: التطبيق العربي الداكن.
- `manifest.webmanifest`: بيانات تثبيت التطبيق.
- `sw.js`: التخزين المؤقت للعمل بعد أول زيارة.
- `icon-192.png` و`icon-512.png` و`icon-512-maskable.png`: أيقونات التطبيق.

## نشر مجاني باستخدام GitHub Pages
1. أنشئ حساباً في GitHub إن لم يكن لديك حساب.
2. أنشئ مستودعاً جديداً (New repository)، واجعله Public، وسمّه مثلاً `daftar-naql`.
3. ارفع جميع محتويات هذا المجلد إلى جذر المستودع، وليس ملف ZIP نفسه.
4. افتح Settings ثم Pages.
5. في Build and deployment اختر Deploy from a branch.
6. اختر الفرع `main` والمجلد `/(root)` ثم Save.
7. انتظر حتى يظهر رابط ينتهي بـ `github.io`.
8. افتح الرابط من Chrome على الهاتف. بعد اكتمال تحميل الصفحة مرة واحدة، افتح قائمة Chrome؛ يفترض أن يظهر خيار «تثبيت التطبيق» أو «إضافة إلى الشاشة الرئيسية».

## تنبيهات مهمة
- التثبيت يتطلب رابط HTTPS؛ GitHub Pages يوفر HTTPS.
- بيانات هذا الإصدار تحفظ في تخزين المتصفح على كل جهاز على حدة. لا توجد مزامنة بين الهاتف والكمبيوتر.
- النسخة الاحتياطية من داخل التطبيق مهمة جداً. لا تعتمد على التخزين المحلي وحده لحفظ سجلات الشركة.
- هذه أداة أولية للتسيير وليست برنامجاً محاسبياً معتمداً أو بديلاً عن مراجعة محاسب مختص بالالتزامات الجزائرية.
